# Hornero — Crea tu Torta

Mobile-first cake customization experience for Hornero, a Colombian artisanal bakery.

## Development

```bash
npm run dev
```

```bash
npm run lint
npm run build
```

Photography assets belong in `public/images/` (`cakes`, `ingredients`, `fillings`, `toppings`, `brand`). Pricing lives in `src/config/pricing.ts` and is consumed only through `calculateCakePrice`.
